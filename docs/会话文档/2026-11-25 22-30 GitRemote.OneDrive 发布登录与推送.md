## 配置与发布

首次配置时，将 `eng/OneDriveClientId.props.example` 复制为 `eng/OneDriveClientId.props`，在 `<OneDriveClientId>` 中填写 Entra 的**应用程序（客户端）ID**。缺少本地配置时可以构建两个程序，联合发布需要有效的 ID。发布时 ID 写入两个程序共用的 Core 程序集，修改发布目录里的 JSON 或环境变量无法覆盖它。更换 ID 后需要重新发布。 [联合发布项目](../../eng/PublishOneDrivePrototype.proj) · [认证实现](../../src/GitRemote.OneDrive.Prototype.Core/Authentication.cs)

在仓库根目录运行发布命令。本机的 .NET 11 SDK 安装在用户目录下。

```powershell
& "$env:USERPROFILE\.dotnet\dotnet.exe" publish .\eng\PublishOneDrivePrototype.proj
```

两个 `.exe` 和共享依赖输出到 `artifacts/publish/onedrive-prototype/Release`。部署时复制整个目录，目标机器需要 Git 和 .NET 11 运行时。以下设置在当前 PowerShell 会话生效。长期使用时可把发布目录加到 Windows 用户 `Path`，并在使用用户目录下的 .NET 时设置 `DOTNET_ROOT`。

```powershell
$publishDir = (Resolve-Path .\artifacts\publish\onedrive-prototype\Release).Path
$env:Path = "$publishDir;$env:Path"
$env:DOTNET_ROOT = "$env:USERPROFILE\.dotnet"
git onedrive help
```

## Entra 登录

1. 在 Entra 的应用注册中选择支持**个人 Microsoft 帐户**的账户类型。在**概述**页复制应用程序（客户端）ID。 [应用注册指南](https://learn.microsoft.com/en-us/entra/identity-platform/quickstart-register-app)
2. 在 **Authentication (Preview) → 设置**中启用**允许公共客户端流**，并在**移动和桌面应用程序**平台配置 `https://login.microsoftonline.com/common/oauth2/nativeclient`。本轮的 `invalid_client` 经微软设备码端点诊断为 `AADSTS70002`，要求应用启用移动或桌面公共客户端登录。 [设备码登录指南](https://learn.microsoft.com/en-us/entra/msal/dotnet/acquiring-tokens/desktop-mobile/device-code-flow)
3. 在 **API 权限 → Microsoft Graph → 委托的权限**中添加 `Files.ReadWrite`。 [Microsoft Graph 权限说明](https://learn.microsoft.com/en-us/graph/permissions-reference#filesreadwrite)

运行 `git onedrive login`，打开终端显示的微软登录网址并输入设备码。授权完成后，终端通过 MSAL 获取令牌并显示 `Signed in as ...`。设备码流程无需本机 `localhost` 回调。之后可用 `git onedrive list` 检查仓库访问。

CLI 和远程助手共用 Windows 加密的 MSAL 缓存。默认路径为 `%LOCALAPPDATA%\GitRemote.OneDrive\msal-<去掉连字符的客户端ID>.cache`。`GITREMOTE_PROTOTYPE_CACHE_DIRECTORY` 可指定缓存目录。`git onedrive logout` 清除当前客户端 ID 对应的本地登录记录。 [认证与缓存实现](../../src/GitRemote.OneDrive.Prototype.Core/Authentication.cs)

## 初始化与推送

先用 `git onedrive url GitRemote` 查询仓库。只有提示 `does not exist` 时才执行初始化。以下命令以当前项目的 `master` 为默认分支。

```powershell
git onedrive init GitRemote --initial-branch master
```

以下命令按需添加本地远程，并在推送前核对地址。

```powershell
$url = git onedrive url GitRemote
if ($LASTEXITCODE -ne 0) { throw '无法获取 OneDrive 仓库地址' }
if ((git remote) -notcontains 'origin-onedrive') {
    git remote add origin-onedrive $url
    if ($LASTEXITCODE -ne 0) { throw '无法添加 OneDrive 远程' }
}
if ((git remote get-url --push origin-onedrive) -ne $url) {
    throw '现有 OneDrive 推送地址与目标仓库不一致'
}
git push origin-onedrive master
if ($LASTEXITCODE -ne 0) { throw '推送到 OneDrive 失败' }
git ls-remote --exit-code origin-onedrive refs/heads/master
```
